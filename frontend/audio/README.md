# Audio assets

- `happy-loop.mp3` — “Happy Loop” by wipics, from OpenGameArt. CC0 / public domain.
- `card-game-sounds/cockatrice/` — game interface and card sounds by HaelDB, from the OpenGameArt “Card Game sounds” pack. CC0.

Sources:

- https://opengameart.org/content/happy-loop
- https://opengameart.org/content/card-game-sounds
